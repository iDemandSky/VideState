# Migrating to 0.5.0

0.5.0 has no breaking changes. Code written for 0.4.0 runs as it is. This page lists the few changes that can show up in
code that uses VideState in an unusual way.

## What to check

| Change | Affects you when | What to do |
| --- | --- | --- |
| [`onTransition`](/guide/handlers#ontransition) callbacks receive a fifth argument, `round`. | Your callback uses `...` or counts its arguments. | Nothing, unless you forward every argument. A callback that lists four parameters works as before. |
| A [`Handler`](/guide/handlers#handler) has a new function, [`playSequence`](/guide/handlers#playsequence), and [`progress`](/guide/handlers#progress). | You wrote a mock or a wrapper that implements the `Handler` type yourself. | Add the two functions to it. |
| [`setState`](/guide/handlers#setstate) can raise a new error when the rule has [`allowedTransitions`](/guide/rules#allowed-state-changes). | You add `allowedTransitions` to an existing rule. | Check that no code changes between states the rule no longer lists. |
| [`everyHandler`](/guide/every-handler) lists handlers in the order they were created. | You depended on the order of an earlier version, which was not defined. | Nothing. The order is now the creation order. |
| The `Schema` entry of the schemas guide no longer has `parse`. | You linked to `/guide/schemas#parse`. | Remove the link. `parse` still exists on a schema, but it is not part of the documented API. |

## New in 0.5.0

None of these needs a change. They are there when you want them:

- [`VideState.union`](/guide/schemas#union) accepts a value of either of two schemas.
- [`VideState.extend`](/guide/rules#extending-a-rule) makes a rule from a base rule.
- [`allowedTransitions`](/guide/rules#allowed-state-changes) limits which state can follow which.
- [`playSequence`](/guide/handlers#playsequence) plays several states in turn, and [`progress`](/guide/handlers#progress)
  gives the alpha of a transition as a source.
- [`bezier`](/guide/transitions#bezier) and [`easing`](/guide/transitions#easing) make an easing of your own.
- [`setReducedMotion`](/guide/transitions#setreducedmotion) makes every state change instant.
- A `delay` option on [`setState`](/guide/handlers#setstate) and a `stagger` option on
  [`everyHandler.setState`](/guide/every-handler#setstate).
- A [manual clock](/guide/testing) for tests.

## Upgrading from an older version

Upgrade one version at a time, and follow the page of each version you pass:

1. [Migrating to 0.3.0](/migration/to-0-3-0), if you use a version before 0.3.0.
2. [Migrating to 0.4.0](/migration/to-0-4-0), if you use a version before 0.4.0.
