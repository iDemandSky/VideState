# Migrating to 0.3.0

0.3.0 renamed `fastForward` to [`scaleSpeed`](/guide/handlers#scalespeed), because a speed below `1` slows a transition
down. It also changed what the scale applies to. This is a breaking change.

## Before and after

```luau
-- 0.2.0
handler.fastForward({ speed = 4 })
```

```luau
-- 0.3.0
handler.scaleSpeed({ speed = 4, once = true })
```

| 0.2.0 | 0.3.0 |
| --- | --- |
| `handler.fastForward(options)` | `handler.scaleSpeed(options)` |
| `FastForwardOptions` | `ScaleSpeedOptions` |
| The speed applied to the running transition only. | The speed applies to every following transition, until you call `scaleSpeed` again. Pass `once = true` to apply it to the running transition only. |

## Steps

1. Rename every `fastForward` call to `scaleSpeed`, and `FastForwardOptions` to `ScaleSpeedOptions`.
2. Add `once = true` to each call that should affect only the running transition, which is what `fastForward` did.
3. If a call should keep the scale for later transitions, leave `once` out.

## New in 0.3.0

[`VideState.everyHandler`](/guide/every-handler) acts on every handler at once, with filters by tag, rule, and state.
Nothing in it replaces an old function, so you do not need to change anything to use it later.
