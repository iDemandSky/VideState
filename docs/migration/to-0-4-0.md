# Migrating to 0.4.0

0.4.0 removed the options of a handler. A handler used to take default tween settings, and every
[`onTransition`](/guide/handlers#ontransition) connection inherited them. Now each connection has its own settings, in
`tweenDefault`, and a setting it leaves out takes the built-in default: `0.25` seconds, linear, speed `1`, no delay.

This is a breaking change. A third argument to `new` raises an error, and so does a tween setting at the top level of
the options of `onTransition`, with a message that points to `tweenDefault`.

## Before and after

The settings of the handler moved to the connections that need them:

```luau
-- 0.3.0 and earlier
const handler = ButtonRule.new(states, "Idle", {
    onTransition = {
        duration = 0.15,
        easing = "quadOut",
    },
})

handler.onTransition(function(_, _, current)
    button.BackgroundColor3 = current.backgroundColor
end)
```

```luau
-- 0.4.0
const handler = ButtonRule.new(states, "Idle")

handler.onTransition(function(_, _, current)
    button.BackgroundColor3 = current.backgroundColor
end, {
    tweenDefault = {
        duration = 0.15,
        easing = "quadOut",
    },
})
```

The options that a single connection already passed also move inside `tweenDefault`:

```luau
-- 0.3.0 and earlier
handler.onTransition(callback, { duration = 0.3 })

-- 0.4.0
handler.onTransition(callback, {
    tweenDefault = {
        duration = 0.3,
    },
})
```

## Steps

1. Remove the third argument of every `new` call.
2. Put the settings that it held into the `tweenDefault` of each `onTransition` call that relied on them.
3. Move the top-level `easing`, `duration`, `speed`, and `delay` of every connection into `tweenDefault`.
4. Remove `HandlerOptions` from your types. It no longer exists.

If many components used the same handler options, keep the settings in one module and pass them to every connection. See
[Tween config](/examples/tween-config).

## Other changes

- Ripple is no longer a dependency. VideState tweens values itself, so installing the package pulls one package fewer.
  The values are the same.
- [`tweenOverrides`](/guide/transitions#overrides-for-state-changes) sets other tween settings for particular state changes.
- [`handler.animate`](/guide/handlers#animate) returns Vide sources that follow a transition, so you can bind a property
  to them instead of writing an `onTransition` callback.
